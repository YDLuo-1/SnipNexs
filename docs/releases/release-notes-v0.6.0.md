# SnipNexs v0.6.0

- 贴图支持以鼠标位置为锚点的连续缩放，并改用轻量直接绘制阴影。
- 全局截图快捷键默认使用 `F1`；被其他程序占用时自动回退到 `Ctrl+Shift+A`。
- 截图时可预览并单击自动选择桌面窗口，也可拖动创建自定义选区。
- 截图提示信息更醒目，标注工具栏改为图标按钮并提供中英文工具提示。
- 截图历史保留原始物理分辨率和图片自身 DPR，正确映射标注；会话内最多 20 张、约 64 MiB。
- 有系统托盘时默认后台启动，截图期间阻止主界面、关于页和重复启动覆盖屏幕。
- 新增中英文“关于 SnipNexs”和离线开源许可页面。
- 便携 ZIP 补齐 Qt 插件、MSVC 应用本地运行库、许可文件与 Qt 6.11.2 SBOM。

应用包、Qt 对应源码和 SHA-256 校验文件作为本 Release 的三个独立附件提供。
