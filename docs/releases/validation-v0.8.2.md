# SnipNexs 0.8.2 本地交付验证

验证日期：2026-10-30。此包来自基于 `2a555a1c163860a237167cb9b236547aaecb066f` 的当前开发树，不代表已经创建 Git 标签或发布到 GitHub。源码与产物摘要见 `artifacts/validation-v0.8.2.json`。

## 已完成

- Release 构建通过。全量 CTest 30 项：29 通过、0 失败、1 跳过，用时 76.29 秒。
- 跳过项为 `NativeTrayIconTests`：当前 Windows build 26300 会话拒绝托盘注册，根因未确定。无托盘时的主窗口显示、最小化、恢复和捕获期间隐藏，由 `MainWindowTests` 验证通过。
- Windows OCR 的两行数字识别通过；编辑原文、切换引擎、双栏文本一致性、全局翻译忙状态通过窗口回归。
- OPUS-MT 英中、中英真实推理通过；Hy-MT2 常规后端和强制 x64 基线后端真实推理通过。离线包预装三个模型，11 个模型文件的尺寸及 SHA-256 与应用目录清单一致。
- 模型安装的大小/哈希校验、超时/取消清理、安装与删除互斥通过；Qt HTTPS 对固定发布地址的 233 字节配置文件下载及校验通过，不据此声称重下了全部模型。
- 系统声音、麦克风分别进行了真实 WASAPI 采集；纯视频、系统声音与麦克风录制均通过。测试 MP4 已自动删除。
- 60 秒系统声音录制：640×360，提交 1741 帧；完整解码 1795 视频帧及 2810 音频块，容器时长 60001 ms，音视频结束时间分别为 59999 / 59946 ms。编码器会按目标帧率补帧，解码帧数不等于采集提交帧数。
- 10 秒整屏麦克风录制：2560×1600，提交 281 帧；完整解码 292 视频帧及 464 音频块，容器时长 9982 ms，音视频结束时间分别为 9933 / 9898 ms。
- 当前会话的 Windows Graphics Capture 返回 `0x80070005`。以上录屏实测走 GDI 区域采集与软件 H.264 兼容路径。修复了实测发现的媒体类型准备失败以及音视频绝对时钟造成的异常时长/积压。
- 音频队列、PCM WinRT 缓冲、退出时等待录制结果、原子完成保存及失败保留非空临时文件，由 `RecordingCoreTests` 验证。退出保存测试使用确定性编码器替身，不冒充真实录制退出验收。
- 发布目录在仅有 Windows System32 的 PATH 下成功启动；无界面运行库自检确认 TLS、CTranslate2、llama 与 CPU 后端从部署目录正常加载。

## 已知验收边界

- 用户按 Esc 停止了桌面控制，之后未再操作窗口。截图触发、主窗口与设置页已有实机观察，但本轮未完成“拖选→OCR→翻译”和“录制中退出”的完整人工操作链路。
- 尚未在干净 Windows 虚拟机、物理旧 CPU、混合 DPI 显示器或数小时连续录制场景验收。当前 CPU 上的 x64 基线推理不能代替旧机器实测。
- 本机未验证 WGC 硬件录屏路径成功；兼容路径有 CPU 拷贝与软件编码开销。Windows 捕获排除属于尽力而为机制。
- 截图首帧的 P95 <100 ms 目标尚未实现，仍保留 120 ms 隐藏窗口等待；本机先前观察到的一次完整截图触发约 504 ms，不当作 P95。
- 编码中断时保留的 `.partial.mp4` 只用于恢复或排查，不能保证一定可播放。

## 使用与交付

运行 `dist/SnipNexs-0.8.2-win64/bin/SnipNexs.exe`。整个目录可移动；不要只复制 EXE。离线 ZIP 包含三个翻译模型，首次翻译无需下载；OCR 使用本机已安装的 Windows 语言能力。

正式发布仍须遵循 `scripts/package-release.ps1` 的干净工作树和版本标签要求，本轮未绕过这些要求发布 GitHub Release。
