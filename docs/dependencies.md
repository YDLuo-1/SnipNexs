# 依赖与许可

| 依赖 | 当前用途 | 链接方式 | 许可证注意事项 |
|---|---|---|---|
| Qt 6 Core/Gui/Widgets/Network | UI、事件循环、单实例通信 | 动态链接 | Qt LGPL；发布 Qt 许可文本并允许替换 DLL |
| Windows SDK | Windows 10 平台 API | 系统组件 | 随 MSVC/Windows SDK 条款 |

当前没有复制 eSearch、Flameshot、Ksnip、ShareX、OBS 或 Snipaste 的源代码。后续引入 ONNX Runtime、OCR 模型或 FFmpeg 前，必须在此文件记录精确版本、来源、构建选项及许可证。
